# Buildicy Platform Architecture

This directory contains the Phase 1 architecture proposal for the Buildicy platform. It is based on the supplied product brief; the project directory had no existing source files or documentation to reconcile.

## Review package

- [Architecture proposal](./proposal.md): boundaries, decisions, API, security, AI design, risks, roadmap, and future-module plans.
- [System architecture](./system-architecture.mmd): Mermaid system context and component diagram.
- [Database ERD](./database-erd.mmd): proposed initial relational model and future extension seams.

No application code, migrations, infrastructure, or deployment configuration has been implemented. These documents are a proposal for review and approval.
